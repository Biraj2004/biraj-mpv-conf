\docheading{mpv Media Player — Comprehensive User Guide}

\subheading{1. Introduction \& System Overview}

\textbf{biraj-mpv-conf} is a clean, optimized configuration suite designed for mpv. It brings a modern user interface, smooth 4K video playback, fast hover thumbnails, and native file dialogs into a single seamless experience.

The key features include:
\begin{itemize}
  \item \textbf{High-Performance Rendering}: Uses the \code{gpu-next} engine with Direct3D 11 Flip presentation for low GPU overhead.
  \item \textbf{HDR10 \& Dolby Vision Tone-Mapping}: Real-time tone mapping tuned for 0-frame-drop playback on standard laptop screens.
  \item \textbf{Dynamic Format Badge Overlay}: Automatic on-screen notification of detected video formats (\code{DV}, \code{HDR10+}, \code{HDR}, \code{HLG}, \code{SDR}).
  \item \textbf{Modern UI}: ModernZ On-Screen Controller with fluent vector icons and interactive right-click context menu.
  \item \textbf{Smart Contextual Profiles}: Automatic profile switching for Picture-in-Picture mode, minimizing, and night audio normalization.
\end{itemize}

\subheading{3. Video Playback \& HDR Performance Tuning}

\begin{itemize}
  \item \textbf{Tone-Mapping Engine}: Configured with \code{vo=gpu-next} and \code{d3d11-flip=yes} for low-overhead DirectX flip-model presentation.
  \item \textbf{Compute Peak Optimization}: Setting \code{hdr-compute-peak=no} uses stream metadata directly, reducing render time to $\sim 25\text{ ms}$ and preventing dropped frames during 4K Remux playback.
  \item \textbf{Display Hinting}: Enables \code{target-colorspace-hint=yes} to pass wide-gamut BT.2020 metadata directly to external HDR displays.
\end{itemize}

\subheading{4. Dynamic Format Badge Overlay}

The included \code{hdr_badge.lua} script automatically detects incoming video properties and announces the format in the top-right corner:
\begin{itemize}
  \item \textbf{DV}: Dolby Vision Profiles 5 and 8.1 streams
  \item \textbf{HDR10+}: Dynamic metadata HDR streams
  \item \textbf{HDR}: Standard PQ and BT.2020 high dynamic range content
  \item \textbf{HLG}: Hybrid Log-Gamma broadcast streams
  \item \textbf{SDR}: Standard Dynamic Range content
\end{itemize}

The badge displays for 5 seconds on launch and can be manually viewed or hidden at any time by pressing \code{l}. When the player is muted, it automatically shifts left to sit beside the speaker icon without collision.
